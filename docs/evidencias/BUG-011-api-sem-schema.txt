BUG-011: API não valida schema, tipos nem campos extras
Gerado em 03/11/2026 contra https://analista-teste.seatecnologia.com.br/employees com requests (sem credencial).
Registros: sintéticos, nome com prefixo QA-AUTO-, apagados em seguida e confirmados por ?id=.
CPF mascarado na exibição; o corpo enviado tem o CPF sintético completo. Registros de terceiros nunca entram.
Todos os corpos mantêm state.employee (nunca se remove state.employee: ver BUG-005).
